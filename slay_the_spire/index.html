PASANG SHADOWSPIRE DI IOS

Untuk memainkan game ini dalam mode aplikasi mandiri layar penuh di iPhone atau iPad:

  1. Buka halaman game ini menggunakan browser Safari.
  2. Ketuk tombol Bagikan (ikon kotak dengan tanda panah ke atas ⬆️ di bilah navigasi bawah Safari).
  3. Gulir ke bawah dan ketuk "Tambah ke Layar Utama" (Add to Home Screen) ➕.
  4. Ketuk "Tambah" (Add) di pojok kanan atas. Ikon ShadowSpire akan muncul di layar depan HP Anda!
